# 翻译说明与抽取记录（translation_notes）

本文件记录 `paper/` 与 `_build/paper-annotated.md` 的生成方式、可核对的口径，以及所有未能完美处理的地方。**读本不替读者猜测**：凡抽取不可靠处，均在正文内标注 `[存疑：…]` 或 `[公式原文见 p.X]`。

## 1. 源文件与产物

| 项 | 值 |
|---|---|
| 源文件 | NVIDIA 官方 PDF `gr00t2_whitepaper.pdf`（135 页，PDF 1.5，LaTeX/pdfTeX 生成，可选中文本层，无扫描页） |
| 文档性质 | NVIDIA 技术报告（2026-11），非同行评审论文 |
| 正文字数（抽取） | 约 412,000 英文词符（不含图表内文字） |
| 本读本 | `_build/paper-annotated.md` 约 571,000 字符，其中中文译文约 160,000 字 |
| 图表 | 106 个（70 图 + 36 表），从原 PDF 裁切为 PNG |
| 公式 | 7 个独立展示公式，裁切为 PNG（`assets/equations/`） |

## 2. 抽取与切块口径

原 PDF 共抽取出 **2,526 个文本块**，按类型分为：

| 类型 | 数量 | 处理 |
|---|---|---|
| 正文段落（S） | 1,004 | 全部翻译，共 866 个锚点进入 `paper.md` |
| 图注/表注（C） | 106 | 全部翻译，附对应图表图片 |
| 小节标题（H） | 76 | 全部翻译（74 个进入读本，2 个属被跳过章节） |
| 独立公式（E） | 7 | 保留原图 + 中文说明 |
| 图表内部标签、页眉、页码、短数学碎片 | 1,333 | **不作为正文翻译**（见 §4） |
| 合并块 | 63 | 跨页断开的同一段落被合并，保留首块 id，原后续 id 记入 `source_map.json` 的 `merged_into` |

跨页段落合并规则：前一块不以句末标点结束、后一块以小写字母或左括号开头、且两块页码相邻——满足则合并为一段，避免中英对照被页边界切断。

## 3. 未翻译的部分（有意跳过，共 232 块 / 40,072 词符）

| 部分 | 页码 | 理由 |
|---|---|---|
| 目录（Contents） | 1–2 | 已用带锚点的中文目录替代 |
| 参考文献（References） | 29–37 | 211 条文献条目，属检索信息而非论证内容；需要时直接查原 PDF |
| 前置页（Front matter） | 1 | 仅封面与版权行 |

此外，图表内部的坐标轴标签、面板标注、表格单元格文字（1,333 块）未单独翻译：这些内容已包含在裁切的图表图片中，逐字翻译反而会与图片重复并打断阅读。

## 4. 图表裁切质量

- 裁切方式：按图注位置向上（图）或向下（表）搜索图形簇包围盒（矢量图形 + 位图 + 短标签块），外扩 4–6 pt 后以 200 dpi 渲染。
- **70 个图 + 36 个表中，96 个为精确裁切**，仅含该图表本身。
- **10 个退化为整页渲染**（`source_map.json` 中 `fallback_page_render: true`）：T009、T013、F038、F048、T019、T021、T030、T031、F068，以及 1 个同类表格。原因是该图表与相邻正文/图表在版面上无足够间隙，自动裁切无法可靠分离。这些图片仍完整包含所需图表，只是多带了同页的相邻内容。
- 少数图表在原 PDF 中被拆成多个绘图对象，裁切后可能包含相邻面板的标注文字——不影响读图，但不要把这些标注当作正文。

## 5. 公式处理（重要）

PDF 文本层对数学公式的抽取**严重残缺**，例如第 52 页的公式被抽成 `𝐾eff = 𝑠acp 𝑘𝑝,`。因此：

- 每个独立展示公式都从原页**裁切为图片**，放在 `assets/equations/E001.png` … `E007.png`，读本中显示原图。
- 公式的数学本体**不做 LaTeX 重排**：宁可不给，也不臆造。
- 正文中行内的数学符号（如 $K$、$k/K$、$10^{-15}$）在能确证时用 `$...$` 渲染；不能确证时保留抽取字符并标注 `[公式原文见 p.X]`。
- `source_map.json` 中 7 个公式条目的 `confidence` 均为 `low`、`latex` 为 `null`、`image_path` 指向裁切图——这是刻意的：它们以原图为准。

校验：`validate_reader_math.py --strict` 通过（0 fail / 0 warn）。

## 6. 术语一致性

全篇以 `GLOSSARY.md` 为唯一标准，35 个翻译分块共用同一份术语表。核心定译：

- world-action model（WAM）= 世界-动作模型；vision-language-action（VLA）= 视觉-语言-动作
- embodiment = 本体；cross-embodiment = 跨本体；x-adapt = 跨本体适配
- teleoperation = 遥操作；post-training = 后训练；action chunk = 动作块
- loco-manipulation = 移动操作；dexterous hand = 灵巧手；parallel-gripper = 平行夹爪
- code-as-policy（CaP）= 代码即策略；visual steering = 视觉引导

模型名、数据集名、硬件名（GR00T 2、GR00T 2 Turbo、SONIC、UMI-10K、Human-1M、DexUMI、GearArena、YAM、Dexter、Tianji、Sharpa、XHAND、G1、Cosmos-Predict2.5-2B、Wan 2.1/2.2 等）一律保留英文原样。

## 7. 已知不足

1. **英文原文块是 PDF 抽取文本**，保留了原 PDF 的换行合并结果，个别地方会出现抽取造成的字符残缺（例如带圈项目符号显示为 `�?`）。遇到这类位置，中文译文按上下文给出，英文保留原样。
2. **少数小节标题被误判为正文段落**（如 `B.1.1. Human Data Capture and Conversion` 出现在 `S869` 而非标题块），因此在读本中显示为普通区块而非带锚点的小节标题。内容与顺序不受影响。
3. **图表未做逐图像素级校对**：10 个整页渲染的图表多含相邻内容（见 §4）；若发现某图裁切不当，直接回原 PDF 对应页查看。
4. **参考文献未翻译**，需要引用核查时请回原 PDF 第 29–37 页。
5. 正文与附录的**数字未做交叉验算**：读本忠实转写原文数字，但原文自身存在表述不一致的可能（例如同一实验在不同章节出现不同试次数），这类问题请以附录中的表为准，并在 `学习指南.md` 第 7 讲的批判性练习中处理。

## 8. 复现方式

本读本由以下脚本生成（均在 `tools/` 下，可重跑）：

| 脚本 | 作用 |
|---|---|
| `build_source.py` | 解析 PDF → `source_map_raw.json`（块级 source map）+ 裁切 106 个图表 + 7 个公式图 |
| `chunk_blocks.py` | 过滤图表内标签、合并跨页段落、按约 14k 词符切成 35 个翻译分块 → `blocks/chunk_XX.json` |
| `assemble.py` | 合并 `chunks/*.md` → `paper.md` + `source_map.json`（含合并别名与公式条目） |

翻译由 35 个并行分块完成，全部通过逐块自检（区块 id 序列、`Original`/`中文` 配对计数、标题数量一致）。
