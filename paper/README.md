# 原文中英对照

这一部分是 NVIDIA《GR00T 2》技术报告（whitepaper）的**全文对照底稿**，共 16 页（正文 5 章 + 附录 A–K）。

## 排版约定

每个小节内是"**英文段 → 中文段**"交替：

```
<a id="S021"></a>              ← 区块锚点，可被其他章节链接
<!-- p.3 S021 -->              ← 来源页码与区块号，渲染时不可见

Building general-purpose robots requires ... （英文原文，与 PDF 抽取文本逐字一致）

构建通用机器人需要这样的模型：...（对应中文译文）
```

- **英文段**：从 PDF 文本层直接抽取，除合并换行外未做改写。可用于核对术语、数字与原始措辞。
- **中文段**：忠实翻译，术语服从[术语表](../appendix/术语表.md)。
- **锚点**：`S`=正文段、`C`=图注/表注、`E`=公式、`H`=小节。课程章节里的引用（如 `p.41 S786`）就是按这套编号定位的。

## 怎么用它

1. **先读课程章节**（第 04–11 章），知道该看什么；再回到对应原文页精读。
2. 英文看不懂时，直接看下一段中文；中文意思对不上时，回头看英文原句——这是判断"是翻译问题还是理解问题"的最快方法。
3. 图表是从原 PDF 裁切的 PNG，插在其图注所在位置。10 个图表因版面无法精确分离而退化为整页渲染，清单见[抽取与翻译说明](../appendix/抽取与翻译说明.md)。

## 未收录的内容

- 目录页与参考文献（p.29–37）：属检索信息，需要时查原 PDF。
- 图表内部的坐标轴标签、面板标注、表格单元格文字：已包含在图片中，不重复翻译。

## 已知限制

- 公式以原图为准，不做 LaTeX 重排（PDF 对数学符号的抽取严重残缺）。
- 少量小节标题被抽取器误判为正文段落，显示为普通区块，内容与顺序不受影响。
- **跨页段落可能被图表切断**：原 PDF 里一个段落跨页、而下一页顶部有图表时，该段落会被图表分成前后两半（约 30 处）。读的时候如果发现一句话没说完，往下找那张图之后接着读。这是按版面顺序抽取的固有代价，不影响内容完整性。

完整说明见[抽取与翻译说明](../appendix/抽取与翻译说明.md)。
